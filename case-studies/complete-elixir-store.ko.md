# Complete Elixir 온라인 스토어

[English](complete-elixir-store.md) · **한국어** · [처음으로](../HOW-I-BUILD.ko.md)

**무엇인가:** [completeelixir.com](https://completeelixir.com). Shopify에서 운영 중인 스킨케어 스토어입니다.

**제 역할:** AI에게 지시해서 스토어를 처음부터 끝까지 만들었습니다. 경쟁사 분석, 디자인 리서치, 문제 찾기, mobile-first 디자인을 했고, 제품 영상, 사진, 캡션도 AI에게 지시해서 만들었습니다. 문제를 하나하나 짚어 AI에게 고치게 하고, 출시 전에 모든 기능을 테스트했습니다.

**리디자인 방식:** 수정은 다섯 라운드에 걸쳐 진행했습니다. 라운드마다 라이브 테마의 사본(CE v2부터 CE v6)에서 작업해서, 라이브 스토어를 직접 건드리지 않았고 어느 라운드든 되돌릴 수 있었습니다. 게시는 항상 사람이 직접 누르는 단계로 남겼습니다.

## 1. 브랜드 파일에서 가져온 디자인 시스템

- 예전 강조색은 브랜드에 없는 코발트 파랑이었습니다. 이제 색은 로고와 브랜드 원본 파일에서만 가져옵니다. 잉크 `#1F2023`, 골드 `#E2AD5B`, 아이보리 `#F3EBDD`, 작은 글자용 브론즈 `#8A6420`(흰 바탕 대비 5.4:1).
- 모든 버튼이 한 가지 스타일을 씁니다. Inter 600, 11.5px, 각진 모서리. 기본은 잉크, 마우스를 올리면 골드.
- 섹션 제목의 대소문자 표기를 하나로 통일했습니다("Shop by skin concern").

## 2. 눈대중이 아니라 숫자로

- 15px에서 183px까지 제각각이던 섹션 간격을 하나로 맞췄습니다. 데스크톱 101px, 모바일 64px.
- 사진과 글이 나란히 있는 블록은 위아래 끝선을 재서 맞췄습니다.
- 375×812 휴대폰 화면에서 헤더를 348px에서 214px로 줄였고, 주요 버튼 두 개가 첫 화면 안에 들어옵니다.
- 1440px, 390px, 375px 폭에서 가로 밀림이 없습니다.

## 3. 자동 검사

- **대비(axe-core, WCAG 2.1 AA):** 모바일 14개 페이지에서 문제 0건. 이후 데스크톱 1440px에서 모든 버튼과 글 속 링크를 기본 상태와 마우스 올림 상태 둘 다 검사했습니다.
- **누른 버튼:** 휴대폰에서는 누른 버튼에 hover 색과 포커스 테두리가 남았습니다. 버튼을 하나씩이 아니라 종류별로 묶어서 고쳤고, 39개 페이지 자동 검사에서 누르면 바뀌는 버튼은 0개입니다. 키보드용 포커스 테두리는 브랜드 색으로 유지했습니다(WCAG 2.4.7).
- **5차 라운드:** 데스크톱 50개 페이지와 모바일 12개 페이지에 새 검사 네 가지를 돌렸습니다. 버튼이 바탕에 묻히는지, 남은 검은 선, 가운데 정렬 섹션 안에서 쏠린 요소, 메뉴 아래 간격. 모두 0건으로 끝났습니다.
- **링크와 연락처:** 33개 페이지의 이메일 주소 69곳이 눌러지지 않았는데, 이제 자동으로 mailto 링크가 됩니다. 내부 링크 37개와 푸터 링크 8개를 확인했습니다.

## 4. 체크리스트가 되는 실수 기록

문제마다 무엇이 틀렸는지, 왜 놓쳤는지, 다음에는 어떻게 할지를 기록합니다. 다섯 라운드 뒤 기록은 32개 항목이고, 그중 30개는 제 검토에서 잡았습니다. 몇 가지 예시입니다.

| 문제 | 왜 놓쳤나 | 지금 규칙 |
|---|---|---|
| 브랜드에 없는 파란 강조색 | 색을 브랜드 파일과 대조하지 않음 | 색은 로고와 브랜드 원본 파일에서만 가져오기 |
| 푸터 칸 하나를 지웠더니 저널(글 209편), VIP, 검색으로 가는 유일한 링크가 사라짐 | 지우기 전에 그 칸의 링크를 확인하지 않음 | 링크를 지우기 전에 다른 곳에도 있는지, SEO 영향은 없는지 확인 |
| 검은 선 하나를 고쳤는데 다른 페이지에 네 곳이 남음 | 지적받은 곳만 고침 | 하나를 지적받으면 사이트 전체에서 같은 종류를 찾아 한 번에 고치기 |
| 휴대폰 폭 하나만 보고 "모바일 끝"이라고 함 | 375px이나 390px 한 폭만 확인 | 어떤 페이지와 폭을 봤고 무엇을 못 봤는지 나눠서 보고 |
| 누른 버튼 색이 계속 바뀜 | 버튼을 하나씩 고침 | 버튼은 종류별로 고치고, 모든 페이지에서 누른 상태를 자동 검사 |

이 규칙들은 이제 새 라운드를 시작하기 전에 체크리스트로 돌립니다.
