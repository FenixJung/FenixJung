### ORBIT (in design)
A macOS menu-bar app that applies one EQ and virtual 7.1 spatial sound to every app, on any headphones.

- Planned stack: Swift 6 + SwiftUI, a C++20 real-time audio core, and Core Audio process taps. Tracked in Jira.

### Agentic job-application workflow
A Claude agent that reads a job posting, tailors a resume, runs review skills, and updates a tracker.
- Connected to Gmail, Google Sheets, and Chrome through MCP connectors; packaged as a reusable Claude skill with local Python tools.
- A human approval step comes before every submission, and personal data stays out of shared files.
